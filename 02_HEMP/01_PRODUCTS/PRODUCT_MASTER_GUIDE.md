# AHUM_PRODUCT_MASTER_2026.xlsx ガイド

ヘンプ製品事業（02 Hemp Products）の商品マスタである `AHUM_PRODUCT_MASTER_2026.xlsx` の内容・使い方を説明するガイドです。**本Excelファイルが商品情報の一次情報源（Source of Truth）であり、このガイドは補助的な説明資料です。**

## Excel の目的

- ヘンプ製品全カテゴリ（衣料・スウェット・寝具・下着・エプロン&タオル類）の原価計算・想定上代（希望小売価格）・卸価格を一元管理する。
- 仕入（工場出し価格・為替・関税・経費）から想定上代までの計算根拠を、カテゴリごとの原価率にもとづいて可視化する。
- 商品企画・価格設定・競合比較の検討材料として使用する。

## 各シートの概要

| シート名 | 内容 |
|---|---|
| `最終一覧表` | 全カテゴリ（衣料・スウェット・寝具・下着・エプロン&タオル）を横断した商品一覧。総原価、想定上代、卸価格（55%/60%）、ahum粗利率、競合参考価格をまとめたサマリー。 |
| `原価・上代マスター(色・関税込)` | 衣料10型について、カラーバリエーションごとの工場出し価格・為替・関税・総原価・想定上代を詳細計算したマスタ。 |
| `型図一覧` | 衣料10型の型図（デザイン）と品番・商品名・カラー展開・数量・想定上代の一覧。 |
| `寝具シリーズ(40%)` | 布団カバー・ボックスシーツ・枕カバーの原価・上代計算（原価率40%）。fog linen work の定価との比較を含む。 |
| `スウェット(35%)` | ヘンプ55%／オーガニックコットン45%のスウェット（S/M/L）の原価・上代計算（原価率35%）。 |
| `下着シリーズ(40%)` | ONE MILE ブランドの下着11型（ベスト・ブラ・アンダーウェア等）の原価・上代計算（原価率40%）。 |
| `下着 図形一覧` | 下着11型の図形（見積書の絵型）一覧。品目・EXW単価・数量・想定上代。 |
| `エプロン&タオル類(40%)` | ハンドタオル・フェイスタオル・バスタオル・ショール・シーツ・エプロンの原価・上代計算（原価率40%）。仕入先 SHANXI ONRAYS の見積書がベース。 |

## 各項目の意味

シートによって列構成は異なるが、共通する主な項目は以下の通り。

| 項目 | 意味 |
|---|---|
| 品番／品目 | 商品を識別するコード（例: `AHM-001`）または商品名 |
| 数量 | 発注・想定ロット数量 |
| 通貨 | 仕入通貨（USD または CNY） |
| EXW単価／工場出し単価（原貨） | 工場出荷時点の単価（現地通貨建て） |
| レート(¥) | 適用為替レート（円換算用。USD=160円、CNY=24円を前提） |
| 工場出し(¥) | 工場出し単価を円換算した金額 |
| 経費(¥) | 運送費等の諸経費（工場出し金額の20%を標準とする） |
| 関税率／関税(¥) | 商品カテゴリのHSコードに応じた関税率、およびその金額 |
| 総原価(¥) | 工場出し＋経費＋関税の合計 |
| 想定上代(税抜／税込) | 総原価を原価率で割り戻して算出した希望小売価格 |
| 卸55%／卸60% | 上代（税抜）に対する標準卸掛率A(55%)・B(60%)で算出した卸価格 |
| ahum粗利率 | (卸価格－総原価)÷卸価格で算出した粗利率 |
| 競合／競合参考上代(税込) | 比較対象とした競合商品とその税込定価 |
| 差（ahum－競合） | 自社想定上代と競合参考価格との差額 |

## 商品カテゴリー

事業内の商品は以下の5カテゴリーに分類されている。

1. **衣料**（AHM-001〜AHM-010）— カシュクールジャケット、ベスト、ブルゾン、パンツ、スカート、ワンピースなど10型。原価率35%。
2. **スウェット** — ヘンプ55%／オーガニックコットン45%混紡、S/M/L展開。原価率35%。
3. **寝具** — 布団カバー（3サイズ）、ボックスシーツ（3サイズ）、枕カバー。原価率40%。
4. **下着**（ONE MILE ブランド、No.1〜No.11）— ベスト、ブラ、アンダーウェア、ジョガー、ワークパンツ。原価率40%。
5. **エプロン&タオル類** — ハンドタオル、フェイスタオル、バスタオル、ショール、シーツ、エプロン。原価率40%。

各カテゴリーの原価率・関税率・為替前提は、対応するシート冒頭の「前提条件」欄に明記されている。

## 商品情報の更新ルール

- **本Excelファイルへの直接編集は、事業責任者の承認を得た上で行う。** Claude Code は本人の明示的な許可なくファイルの上書き・削除・データ変更を行わない。
- 新商品を追加する場合は、該当カテゴリーのシートに行を追加し、`最終一覧表` にも反映する。
- 為替レート・経費率・関税率などの前提条件（黄色セル相当の項目）を変更すると、シート内の関連する計算がすべて再計算される。変更時は変更日・変更理由を [../10_HISTORY](../10_HISTORY/README.md)（※未作成の場合は同様の履歴フォルダ）に記録する。
- 価格改定を行った場合は、旧価格・新価格・改定日をあわせて記録し、見積書・カタログなど関連資料にも反映する。

## データ入力時の注意点

- **通貨・為替レートを必ず確認する。** USD建てとCNY建ての商品が混在しており、レートが誤っていると総原価・上代の計算がすべてずれる。
- **関税率はHSコード（商品分類）によって異なる。** 衣料・スウェットと寝具・タオル類・エプロンでは適用税率が異なるため、新商品追加時はHSコード区分を確認してから入力する（シート内の注意書きに「要確認」「要確定」と記載がある項目は特に注意）。
- **逆算値・仮置き値に注意する。** `エプロン&タオル類(40%)` シートのエプロン単価のように、見積書に直接記載がなく他の合計金額から逆算した値が含まれる場合がある。該当箇所はシート内の注記を確認し、確定情報が得られ次第更新する。
- **数量未確定・要再設定の項目がある。** 例: 寝具シリーズの枕カバーはEXW単価が割安で上代が相場を下回っており、シート内で「要再設定」と注記されている。こうした項目は商談・発注前に見直すこと。
- **本マスタには顧客ごとの個別割引率・取引条件を含めない。** `最終一覧表` の卸55%／卸60%は全取引先に共通して適用しうる標準的な卸価格帯（掛率A/B）であり、特定の取引先向けに合意した個別の割引率・特別条件ではない。特定顧客との個別交渉条件（掛率の上乗せ値引き、支払条件等）は、本マスタではなく [../../08_BUSINESS/01_CUSTOMERS](../../08_BUSINESS/01_CUSTOMERS/README.md) の顧客マスタ・取引条件管理側で別途記録すること。

## 将来の連携方針

- **freee（会計）**: 本マスタの品番・商品名・総原価・想定上代を、freeeの品目マスタ・仕入登録・売上登録と紐づける想定。連携時は品番（例: `AHM-001`）を共通キーとして使用する。
- **見積書**: 見積書発行時は、本マスタの想定上代・卸価格（55%／60%）を基準とし、顧客固有の割引条件は [../../08_BUSINESS/05_ESTIMATES](../../08_BUSINESS/05_ESTIMATES/README.md) 側の見積データで個別に適用する。本マスタ自体は書き換えない。
- **請求書**: 見積・受注確定後の請求書発行は [../../08_BUSINESS/06_INVOICES](../../08_BUSINESS/06_INVOICES/README.md) で管理し、本マスタの品番・価格情報を参照する。
- **在庫管理**: 品番（AHM-001等）およびカラー・サイズ展開を [../../08_BUSINESS/04_INVENTORY](../../08_BUSINESS/04_INVENTORY/README.md) の在庫マスタのキーとして使用し、本マスタとは連動しつつも在庫数量は別管理とする。
- 連携が実装されるまでは、本Excelを唯一の商品マスタとして扱い、他ドキュメントからは参照・引用にとどめる。
