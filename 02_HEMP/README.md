# 02 Hemp Products

ヘンプ（麻）製品事業に関するすべての資料・業務を管理するフォルダです。

## 目的

- ヘンプ素材を使った各種製品の企画・製造・販売を統括する。
- 生地から最終製品までのサプライチェーン、OEM、工場との連携を整理する。

## 取り扱い製品カテゴリ

- Fabric（生地）
- Underwear（下着）
- Apparel（アパレル）
- Bedding（寝具）
- Aprons（エプロン）
- Lifestyle Goods（生活雑貨）
- Sweatwear（スウェット類）
- OEM（受託製造）
- Factories（工場・製造委託先）

## 含める内容の例

- 素材・生地の仕様、調達先情報
- 製品ごとの企画書・仕様書・サンプル管理
- OEM 案件の見積・進行管理
- 工場との契約・生産スケジュール
