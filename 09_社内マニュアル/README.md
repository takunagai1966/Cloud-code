# 09 社内マニュアル (Company Manual)

会社の各種マニュアル・ルール・ナレッジを管理するフォルダです。

## 目的

- 業務手順、社内ルール、運用ノウハウを文書化して蓄積する。
- 誰が作業しても同じ品質で進められるよう、標準化された手順を維持する。

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| `01_業務手順書/` | 業務マニュアル・作業手順書（SOP） |
| `02_社内規程/` | 社内規程・ルール |
| `03_ブランドガイドライン/` | ブランドガイドライン・表記ルール |
| `04_トラブル対応FAQ/` | よくある質問・トラブル対応の記録 |

各フォルダの詳細な用途は、フォルダ内の README.md を参照してください。
