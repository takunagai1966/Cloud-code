# ChatGPT 連携

ChatGPT（OpenAI）で行った作業内容を、このリポジトリの事業領域（01〜09）に取り込むためのフォルダです。

## 前提

- 2026-07-11 時点で、ChatGPT の API 連携（自動同期）は未設定です。
- そのため現状は **手動での取り込み運用** とします。API 連携（OpenAI API キーの発行・自動化スクリプト等）が必要になった場合は、別途相談のうえ設計します。

## 取り込みの手順

1. **ChatGPT側で書き出す**
   - 個別の会話：右上の共有メニューから該当メッセージ／会話をコピー、または「共有リンク」を作成する。
   - まとめて書き出したい場合：ChatGPT の「設定 → データ管理 → データのエクスポート」から `conversations.json` を取得できる（メール添付でダウンロードリンクが届く）。
2. **保存先の事業領域を判断する**
   - 内容がどの事業領域（01 VIVANI／02 Hemp／03 Furniture／04 HISSAN／05 Food／06 Others／07 AI Automation／08 Business Management／09 Company Manual）に属するかを判断する。
   - 迷う場合はここ（`07_AI_AUTOMATION/ChatGPT連携/`）に一旦置き、後で該当領域に移動する。
3. **`TEMPLATE.md` を使ってMarkdownで保存する**
   - ファイル名は `YYYY-MM-DD_タイトル.md` とする。
   - 出典（ChatGPTの共有リンク等）と要点をあわせて記録し、後から検索・参照しやすくする。

## 含める内容の例

- ChatGPT で作成した企画書・文案・分析結果の最終版
- 参考にした ChatGPT とのやり取りの要点（全文コピペではなく要約推奨）
- 取り込み時の出典リンク・日付
