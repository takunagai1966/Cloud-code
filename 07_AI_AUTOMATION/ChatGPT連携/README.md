# ChatGPT 連携

ChatGPT（OpenAI）で行った作業内容を、このリポジトリの事業領域（01〜09）に取り込むためのフォルダです。

## 前提

- ChatGPT（chat.openai.com のアプリ・Web版）には、過去の会話を自動取得できる公開APIはありません。
- そのため「自動取り込み」とは、**ChatGPTの手動エクスポート → スクリプトによる自動仕分け** を指します（完全な自動同期ではありません）。
- OpenAI API を使った連携（Assistants/Threads API等）は、プログラムから作った会話にしか使えず、通常のChatGPTアプリの会話履歴には使えないため、現状は採用していません。

## 自動取り込みの手順

1. **ChatGPT側でエクスポートする**
   - ChatGPT の「設定 → データ管理 → データのエクスポート」を実行する。
   - 数分〜数十分後にメールでダウンロードリンクが届く。zipを展開すると `conversations.json` が含まれる。
2. **エクスポートファイルを配置する**
   - `inbox/conversations.json` としてこのファイルを置く（`inbox/` はgit管理外）。
3. **仕分けスクリプトを実行する**
   ```bash
   python3 "07_AI_AUTOMATION/ChatGPT連携/scripts/import_chatgpt.py"
   ```
   - 各会話をタイトル・本文のキーワードから事業領域（01〜09、判定できないものは `06_OTHERS`）に自動分類する。
   - `imported/<事業領域>/YYYY-MM-DD_タイトル.md` としてMarkdown化して保存する。
   - 取り込み済みの会話は `imported/imported_ids.json` で管理し、再実行しても重複取り込みしない。
   - 実行結果は `imported/import_log.md` に追記される。
4. **人の目で確認する**
   - キーワードによる自動分類は精度に限界があるため、`import_log.md` を見て誤分類がないか確認し、必要なら該当ファイルを正しい事業領域フォルダへ手動で移動する。
   - 各ファイルの「要点」欄は空欄で生成されるため、必要に応じて追記する。

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| `inbox/` | ChatGPTからエクスポートした `conversations.json` の置き場所（git管理外） |
| `imported/` | 自動仕分け後のMarkdownファイル（事業領域ごとのサブフォルダ）と実行ログ |
| `scripts/` | 取り込み用スクリプト（`import_chatgpt.py`） |

## 個別の会話だけ取り込みたい場合（手動運用）

まとめてエクスポートするほどでない場合は、`TEMPLATE.md` を使って手動でMarkdownを作成し、該当する事業領域フォルダに保存してもよい。

## 含める内容の例

- ChatGPT で作成した企画書・文案・分析結果の最終版
- 参考にした ChatGPT とのやり取りの要点（全文コピペではなく要約推奨）
- 取り込み時の出典リンク・日付
