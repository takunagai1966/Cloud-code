# 03 ジョイント開発・特許 R&D (Joint & Patent R&D)

USM Haller の次世代版を目指す、新規ジョイント金具の開発と特許化に関する資料を管理するフォルダです。

## 目的

- USM Haller のボールジョイントを技術的に分析し、同等以上の機能を持ちながら機構的に異なる、独自のジョイント金具を開発する。
- 開発したジョイントの特許出願・知財戦略を検討・記録する。

## 取り扱い上の注意（重要）

このフォルダの内容は将来の特許出願に関わる可能性がある。特許は原則として「出願前に公になっていない発明」であることが要件のため、下記を徹底すること。

- **出願前に社外・Web等へ無防備に公開しない。** 石巻工房など製作パートナー候補を含め、第三者に見せる場合は必ず秘密保持契約（NDA）を締結してから行う。
- 本フォルダの内容はエンジニアリング面のアイデア出しであり、特許性・侵害リスクについての法的判断ではない。出願前に弁理士による正式な先行技術調査とクレーム設計を必ず行う。

## 含める内容の例

- USM Haller ジョイントの技術分析（[USM_JOINT_ANALYSIS_AND_NEXT_GEN_CONCEPT.md](./USM_JOINT_ANALYSIS_AND_NEXT_GEN_CONCEPT.md) を参照）
- 新規ジョイント候補案・模式図（[diagrams/](./diagrams/)）
- 先行技術調査の記録、弁理士とのやり取り
- 試作・強度検証の記録
- 出願スケジュール・出願書類の下書き
