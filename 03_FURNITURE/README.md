# 03 Furniture

家具事業に関するすべての資料・業務を管理するフォルダです。

## 目的

- 家具の企画・仕入・製造・販売に関する情報を集約する。
- 製品デザイン、素材、製作先、販売チャネルを整理する。

## 含める内容の例

- 製品ラインナップ・デザイン資料
- 素材・木材などの調達情報
- 製作所・職人・工場との連絡記録
- 価格表・見積・受注管理
- 展示会・販売企画

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| `01_PRODUCTS/` | 商品ラインナップ・デザイン資料・企画書 |
| `02_MANUFACTURERS/` | 製作所・パートナー候補・打診記録 |
| `03_JOINT_PATENT_RND/` | 独自ジョイント金具の技術開発・特許戦略（取り扱い注意） |
| `04_DESIGN_CONTRACT/` | 外部デザイナーとの契約条件（開発費・ロイヤリティ・知財帰属）の検討記録 |

各フォルダの詳細な用途は、フォルダ内の README.md を参照してください。

## システム家具ライン: シリーズ1・シリーズ2について（重要）

「拡張できるモジュラー什器システム」というコンセプトは共通だが、**素材・構造が全く異なる2つの独立したシリーズ**として企画している。両者を混同しない・混ぜないこと（例: シリーズ2に合板を使う、シリーズ1にスチール板を使う、といったことはしない）。

| | シリーズ1 | シリーズ2 |
|---|---|---|
| 素材 | 合板 ＋ ジョイント（カムロック等） | 真鍮（ジョイント）＋ スチールポール ＋ スチール板 |
| ポジション | USM Haller を合板と日本のものづくりで再解釈 | USM Haller の次世代版（独自ジョイントで特許取得を目指す） |
| 製作パートナー | Takashima Woodwork Sdn. Bhd.（マレーシア、要確認） | 未定 |
| 参考モデル（製作パートナーではない） | 石巻工房 | — |
| 詳細資料 | [01_PRODUCTS/SYSTEM_FURNITURE_CONCEPT.md](./01_PRODUCTS/SYSTEM_FURNITURE_CONCEPT.md) | [03_JOINT_PATENT_RND/USM_JOINT_ANALYSIS_AND_NEXT_GEN_CONCEPT.md](./03_JOINT_PATENT_RND/USM_JOINT_ANALYSIS_AND_NEXT_GEN_CONCEPT.md) |
| 特許出願の予定 | なし | あり（ジョイント金具、出願前は社外共有NDA必須） |
