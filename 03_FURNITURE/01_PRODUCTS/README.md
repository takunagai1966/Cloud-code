# 01 商品ラインナップ・デザイン資料 (Products)

家具事業の商品企画・デザイン資料を管理するフォルダです。

## 目的

- 新規ライン・シリーズの企画書、コンセプト資料を保管する。
- 製品仕様（寸法、素材、接合方式、カラー展開など）を整理する。

## 含める内容の例

- 商品企画書・コンセプトシート
- 製品ラインナップ一覧・仕様書
- デザイン検討資料（スケッチ、参考事例、ベンチマーク調査）
