# 02 製作所・パートナー管理 (Manufacturers)

家具の製作を委託する工房・工場・職人との情報を管理するフォルダです。

## 目的

- 製作候補先・取引中の製作パートナーの情報を整理する。
- 打診・商談・発注のやり取りを記録する。

## 含める内容の例

- 製作パートナー・参考モデルの情報（[PARTNER_CANDIDATES.md](./PARTNER_CANDIDATES.md) を参照。デザインの参考モデルと、実際の製作パートナーは別に区別して記載する）
- 打診・商談の記録
- 見積・契約条件

正式に取引が始まった製作先は、[08_BUSINESS/02_SUPPLIERS/SUPPLIER_MASTER.md](../../08_BUSINESS/02_SUPPLIERS/SUPPLIER_MASTER.md) の仕入先マスタにも登録する。
