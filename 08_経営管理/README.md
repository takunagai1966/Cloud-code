# 08 経営管理 (Business Management)

会社全体の経営・管理業務に関する資料を管理するフォルダです。

## 目的

- 経営、財務、法務、労務など全社的な管理業務を集約する。
- 事業横断の意思決定や経営数値を整理する。

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| `01_顧客管理/` | 顧客マスタ・取引条件 |
| `02_仕入先管理/` | 仕入先マスタ |
| `03_商品管理/` | 全社共通の商品台帳 |
| `04_在庫管理/` | 在庫マスタ・発注点管理 |
| `05_見積書管理/` | 見積書 |
| `06_請求書管理/` | 請求書 |
| `07_契約書管理/` | 契約書・法務資料 |
| `08_freee連携/` | freee（会計・財務）連携 |
| `09_輸出入管理/` | 輸出入・通関業務 |
| `10_財務管理/` | 財務・経営数値 |

各フォルダの詳細な用途は、フォルダ内の README.md を参照してください。

## 含める内容の例

- 経営計画・予算・実績
- 労務・人事
- 銀行など対外関係の管理
