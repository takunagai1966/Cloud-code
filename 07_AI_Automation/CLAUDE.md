# 07 AI Automation

このフォルダは **AI・自動化に関する取り組み** を管理します。
ルートの `CLAUDE.md`（会社全体の方針）を前提としたうえで、本エリア固有のルールを定義します。

## このエリアの目的

会社の業務（01〜09）を横断して、AI と自動化で効率化・省力化する仕組みを設計・記録します。
Claude Code を「運用パートナー」として活用するための土台づくりの場です。

## このフォルダで扱う内容

- 業務自動化のアイデア・要件・設計
- 各種連携（GitHub / freee / Gmail / Google Drive / Google Calendar）の設定・手順
- プロンプト、テンプレート、ワークフローの管理
- 自動化スクリプト・設定ファイル

## サブフォルダの目安

- `integrations/` — 外部サービス連携の設定・手順
- `workflows/` — 業務フロー・自動化の設計
- `prompts/` — 再利用するプロンプト・テンプレート
- `scripts/` — 自動化スクリプト

## 運用ルール

- 連携（GitHub / freee / Gmail / Google Drive / Google Calendar）は、実際に設定されるまで **認証情報・API・コネクタが存在すると仮定しない**。
- 認証情報・トークン・シークレットは **リポジトリにコミットしない**。
- 設計や手順は **日本語** で記録する。
- まず小さく実行可能な単位で自動化し、動作を確認してから広げる。

## 連携予定（設計時に考慮）

- GitHub — バージョン管理・協働
- freee — 会計・財務
- Gmail — メール
- Google Drive — ドキュメント / ファイル
- Google Calendar — スケジュール
