# 07 AI自動化 (AI Automation)

社内業務の AI 活用・自動化に関する資料・仕組みを管理するフォルダです。

## 目的

- Claude Code をはじめとする AI を使った業務自動化の設計・運用を統括する。
- 各事業（01〜06）を横断して効率化できるワークフローを整備する。

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| `01_ワークフロー/` | 自動化ワークフローの設計・手順 |
| `02_外部連携/` | 外部サービス連携の設定・仕様（GitHub / freee / Gmail / Google Drive / Google Calendar） |
| `03_プロンプト集/` | プロンプト・テンプレート集 |
| `04_運用ルール/` | 運用ルール・改善記録 |

各フォルダの詳細な用途は、フォルダ内の README.md を参照してください。
