# 02 外部連携 (Integrations)

外部サービス連携の設定・仕様を管理するフォルダです。

## 目的

- 各外部サービスとの連携方式・認証方法・データの流れを文書化する。
- 連携ごとの権限範囲を明確にし、意図しない操作を防ぐ。

## 連携予定のサービス

| サービス | 用途 | 状態 |
|---|---|---|
| GitHub | ソース・文書のバージョン管理 | 連携済み |
| freee | 会計・財務 | 未連携 |
| Gmail | メール業務 | 未連携 |
| Google Drive | ファイル保管 | 未連携 |
| Google Calendar | スケジュール管理 | 未連携 |

## 含める内容の例

- サービスごとの接続手順・認証設定の記録
- 連携で扱うデータ項目とマッピング定義
- 権限範囲（読み取り専用／書き込み可）の取り決め

## 注意事項

**認証情報（APIキー、トークン、パスワード等）は本リポジトリに保存しない。** 設定手順や参照先のみを記載する。
