# 01 ワークフロー (Workflows)

業務自動化ワークフローの設計・手順を管理するフォルダです。

## 目的

- 繰り返し発生する業務を、誰が実行しても同じ結果になる手順として定義する。
- 事業領域（01〜06）を横断して使い回せる自動化の型を蓄積する。

## 含める内容の例

- ワークフローごとの設計書（目的・入力・処理・出力・実行頻度）
- 実行手順書、および手動オペレーションとの切り分け
- 自動化の対象業務リストと、優先度・効果の整理

## 注意事項

外部サービスへの書き込みを伴う自動化（メール送信、会計データ登録など）は、実行前の承認プロセスを手順に明記する。
