# 01 VIVANIチョコレート (VIVANI Chocolate)

VIVANI チョコレート事業に関するすべての資料・業務を管理するフォルダです。

## 目的

- VIVANI チョコレートの輸入・販売・マーケティングに関する情報を集約する。
- 商品ラインナップ、価格、在庫、仕入先とのやり取りを整理する。
- 販促企画、卸・小売との取引、キャンペーン資料を保管する。

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| `01_商品/` | 商品マスタ・商品仕様 |
| `02_価格表/` | 価格表・見積書 |
| `03_輸入/` | 輸入・通関関連資料 |
| `04_仕入先/` | 仕入先・メーカー情報 |
| `05_マーケティング/` | マーケティング・販促企画 |
| `06_認証許認可/` | 認証・許認可書類 |
| `07_画像/` | 商品画像・素材 |
| `08_カタログ/` | 商品カタログ |
| `09_新商品/` | 新商品・導入検討中の商品 |
| `10_履歴/` | 過去の取引・価格改定履歴 |

各フォルダの詳細な用途は、フォルダ内の README.md を参照してください。
