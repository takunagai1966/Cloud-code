# 11 税務調査対応 (Tax Audit 2026)

2026年7月末の税務調査に向けた準備状況を管理するフォルダです。

## 目的

- 対象3期分（R5・R6・R7年10月期）について、freee に未登録の資料（契約書・請求書・レシート等）の収集状況を追跡する。
- 決算書（3期分）・年末調整ファイル（R4〜R7年分）の所在確認状況を管理する。

## 重要な注意事項

**このフォルダには実際の請求書・契約書・レシート・通帳等のスキャンデータ本体は保存しないでください。** 本リポジトリは GitHub にプッシュされるため、機密性の高い財務書類の実体をコミットすると情報漏洩のリスクがあります。

- 実データ（PDF・画像等）は iCloud Drive 側に、下記と同じフォルダ構成で保管してください。
  ```
  iCloud Drive/税務調査対応_2026/
    01_R5年10月期/
    02_R6年10月期/
    03_R7年10月期/
    04_決算書_3期分/
    05_年末調整_R4-R7/
  ```
- このリポジトリ内のファイルは「収集状況・進捗を管理するチェックリスト」としてのみ使用します。

## 対象事業年度

| 事業年度 | 期間 |
|---|---|
| R5年10月期 | 2022年11月〜2023年10月 |
| R6年10月期 | 2023年11月〜2024年10月 |
| R7年10月期 | 2024年11月〜2025年10月 |

## 準備が必要なもの（税理士からの依頼事項）

1. 対象3期分で freee に保存していない資料（契約書・請求書・レシート等）
2. 決算書ファイル（3期分）
3. 年末調整ファイル（R4年〜R7年分）

※ 個人口座で会社に関連するものは freee に連携済みのため、通常の freee 突き合わせ作業の対象に含める（別枠での収集は不要）。
