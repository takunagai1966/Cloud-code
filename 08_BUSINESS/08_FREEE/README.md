# 08 freee 連携 (FREEE)

会計・財務クラウドサービス「freee」との連携に関する情報を管理するフォルダです。

## 目的

- freee との連携設定・運用ルールを整理する。
- 請求書・経費・仕訳データの freee 連携フローを管理する。

## 含める内容の例

- freee 連携の設定・API 仕様（連携が有効化された時点で追記）
- freee 上の勘定科目・仕訳ルール
- 連携に関する運用手順・トラブル対応記録

## 注意事項

現時点では freee との連携は未接続です。認証情報・API 接続情報は、実際に連携が設定されたセッションでのみ扱ってください。
