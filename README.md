# Cloud-code

株式会社 ahum.organics の **AI Business Operating System** リポジトリです。
複数の事業ラインと社内業務を横断的に管理するための作業基盤として、Claude Code がオペレーションパートナーとして機能します。

詳細な運用ガイドラインは [CLAUDE.md](./CLAUDE.md) を参照してください。

- 会社概要: [COMPANY_PROFILE.md](./COMPANY_PROFILE.md)
- 事業運営方針: [BUSINESS_POLICY.md](./BUSINESS_POLICY.md)
- 進行中タスク: [TODO.md](./TODO.md)
- 変更履歴: [CHANGELOG.md](./CHANGELOG.md)

## フォルダ構成

事業領域ごとに番号付きフォルダで管理しています。各フォルダの README に詳細な用途を記載しています。

| フォルダ | 内容 |
|---|---|
| `01_VIVANI/` | VIVANI チョコレート事業 |
| `02_HEMP/` | ヘンプ製品事業（生地・下着・アパレル・寝具・エプロン・生活雑貨・スウェット・OEM・工場管理） |
| `03_FURNITURE/` | 家具事業 |
| `04_HISSAN/` | HISSAN 陶器事業 |
| `05_FOOD/` | 食品事業 |
| `06_OTHERS/` | その他・未分類案件 |
| `07_AI_AUTOMATION/` | AI 活用・業務自動化 |
| `08_BUSINESS/` | 経営・管理業務 |
| `09_COMPANY_MANUAL/` | 社内マニュアル・ルール |
