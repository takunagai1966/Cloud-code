## フォルダ構成

事業領域ごとに番号付きフォルダで管理しています。各フォルダの README に詳細な用途を記載しています。

| フォルダ | 内容 |
|---|---|
| `01_VIVANIチョコレート/` | VIVANI チョコレート事業 |
| `02_ヘンプ製品/` | ヘンプ製品事業（生地・下着・アパレル・寝具・エプロン・生活雑貨・スウェット・OEM・工場管理） |
| `03_家具/` | 家具事業 |
| `04_HISSAN陶器/` | HISSAN 陶器事業 |
| `05_食品/` | 食品事業 |
| `06_その他/` | その他・未分類案件 |
| `07_AI自動化/` | AI 活用・業務自動化 |
| `08_経営管理/` | 経営・管理業務 |
| `09_社内マニュアル/` | 社内マニュアル・ルール |

### 命名ルール

フォルダ名は **「2桁の番号 + アンダースコア + 日本語名」** で統一しています（例: `07_AI自動化`、`01_商品`）。番号は表示順を固定するためのもので、日本語名は各フォルダの README の見出しと一致させています。新しいフォルダを追加する際も、この形式に従ってください。
