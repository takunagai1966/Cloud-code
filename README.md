# 株式会社 ahum.organics — AI Business Operating System

このリポジトリは、株式会社 ahum.organics の事業をエンドツーエンドで運用するための
**AI ビジネス・オペレーティング・システム** です。Claude Code を単なるコーディング補助ではなく、
**長期的な運用パートナー** として活用します。

会社全体の方針は [`CLAUDE.md`](./CLAUDE.md) を参照してください。

## 基本ルール

- **作業言語は日本語**（外部・海外向けの正式な文書は国際的なビジネス英語）。
- 新しいコンテンツは、どの番号エリアに属するかを判断して配置する。
- 連携予定サービス（GitHub / freee / Gmail / Google Drive / Google Calendar）は、
  実際に設定されるまで利用可能と仮定しない。
- 認証情報・トークン・シークレットはコミットしない。
